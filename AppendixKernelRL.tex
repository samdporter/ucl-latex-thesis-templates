\section[Kernelised Richardson--Lucy deconvolution]{Kernelised Richardson--Lucy Deconvolution}
\label{app:kernel_rl}

\href{https://github.com/samdporter/Kernel_RL}{\texttt{Kernel\_RL}} implements the \gls{rl}, \gls{krl}, \gls{hkrl} and \gls{rldtv} methods evaluated in Chapter~\ref{chapter:deconvolution_pvc}, using the Core Imaging Library \cite{jorgensenCoreImagingLibrary2021}. The kernel operator supports PyTorch/CUDA and Numba backends for GPU and CPU execution, respectively. The package is released under the MIT licence; its repository provides installation instructions and a Docker environment reproducing the experimental software configuration.
