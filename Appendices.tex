\chapter{Software Contributions}
\label{app:software}

The software developed or adapted for this thesis comprises a Python interface to \glsentryshort{simind}, a \glsentryshort{sirf} integration of a published scatter estimator, and an anatomy-guided deconvolution package. Their roles and availability are summarised below.

\section[\texttt{simind-python-connector}]{\texttt{simind-python-connector}}
\label{app:simind_python_connector}

\texttt{simind-python-connector} connects \gls{simind} Monte Carlo simulations \cite{ljungberg_monte_1989,ljungbergSIMINDMonteCarlo2012} to the reconstruction workflows of Chapters~\ref{chapterlabel3} and~\ref{chapter:paper}. It configures voxel phantoms, energy windows and runtime switches, writes SIMIND input files, executes the simulation, and loads Interfile projections as NumPy arrays. Adaptors provide native data representations for \gls{stir}, \gls{sirf} and PyTomography \cite{thielemansSTIRSoftwareTomographic2012a,ovtchinnikovSIRFSynergisticImage2020,polson_pytomography_2025}.

The main integration task is reconciling geometry conventions: \glsentryshort{stir}/\glsentryshort{sirf} image arrays use \texttt{(z, y, x)}, PyTomography uses \texttt{(x, y, z)}, and raw Interfile projections use \texttt{(views, bins, axial)}. The connector also converts millimetre voxel sizes to the centimetre-based SIMIND geometry. Pure-Python tests cover configuration, parsing and density conversion; backend-dependent tests and Docker examples exercise the reconstruction interfaces.

Version \texttt{1.0.1} is archived at \href{https://doi.org/10.5281/zenodo.19605413}{doi:10.5281/zenodo.19605413}; source code and usage instructions are available in the \href{https://github.com/samdporter/simind-python-connector}{public repository}. SIMIND remains a separately licensed external dependency and is not distributed with the package, which is independent of the SIMIND project.
